# QSLauto — site and releases

Landing page for **QSLauto**, automatic e-mail QSL cards for WSJT-X, by UR6LUE.

- `index.html`, `assets/` — the GitHub Pages site (EN / UK / RU)
- `script/` — the original Python script (`autoqsl.py`), its launcher and a config template
- **Releases** — desktop builds for macOS, Windows and Linux, uploaded automatically by CI

The desktop app source is maintained separately.
